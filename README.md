# Искра — остров поверх экрана

Остров с глазами сверху экрана. Нажми — раскроется: время, погода, батарея, музыка, фонарик, секундомер, громкость.
Свайп вверх — свернётся. Когда начинается музыка, остров сам показывает трек.

## Где что менять
- `app/src/main/assets/island.html` — вид и содержимое острова (можно открыть в браузере Acode для предпросмотра). Тут же `LAT`/`LON` для погоды.
- `app/src/main/assets/app.html` — экран приложения.
- `IslandController.kt` — `TOP_MARGIN` (отступ от верха экрана, dp) и размеры.

## Сборка
`git push` → вкладка Actions → Build APK → Artifacts → `iskra-island-apk`.

## Настройка на телефоне
Открой «Искру» и пройди три пункта. Доступ к уведомлениям нужен для музыки и чтобы остров не пропадал после смахивания.


## Версия 0.6 (архив iskra-island-v6.zip)

- Исправлено окно касаний: у невидимого ловца больше нет флагов `LAYOUT_NO_LIMITS` и `LAYOUT_IN_SCREEN`, которые на некоторых прошивках могли захватывать верхнюю системную область.
- Обложка альбома скрыта в свёрнутом острове и остаётся в открытом музыкальном блоке.
- Добавлены настройки темы (золотая, голубая, фиолетовая, зелёная), масштаба и вертикального положения.
- Добавлены переключатели погоды, музыкального блока, батареи, фонарика, секундомера и субтитров.
- Настройки сохраняются в SharedPreferences и применяются к острову.
