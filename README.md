# Искра — остров поверх экрана

Android-приложение: сверху по центру экрана плавает «остров» с глазами Искры.
Нажми на него — раскроется (часы, дата, погода, батарея). Нажми ещё раз — свернётся.

## Где что менять
- `app/src/main/assets/island.html` — весь внешний вид и содержимое острова (HTML/CSS/JS). Тут же `LAT`/`LON` для погоды.
- `app/src/main/java/com/iskra/island/IslandService.kt` — размеры острова в dp (`COLLAPSED_*`, `EXPANDED_*`) и отступ от верха экрана (`TOP_MARGIN`).

## Сборка APK
Залей проект в GitHub-репозиторий. Вкладка Actions → Build APK → внизу в Artifacts скачай `iskra-island-apk`.
Распакуй zip, поставь `app-debug.apk`.

## Первый запуск
Открой приложение «Искра» → «Включить остров» → разреши «Поверх других приложений» → вернись и нажми ещё раз.
